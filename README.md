A responsive, dependency-free **3D coverflow image gallery** with cinematic CSS scenes, smooth transitions, and full keyboard & touch support. No libraries. No build tools. Just pure web.

---

## ✨ Features

- 🎠 **CSS 3D perspective** with layered card depth and `transform-style: preserve-3d`
- 🎨 **5 cinematic scenes** — all crafted purely in CSS (no image downloads needed)
- ⌨️ **Keyboard navigation** — `←` / `→` arrow keys
- 👆 **Touch & pointer swipe** — mobile-friendly drag support
- ⏯️ **Autoplay** with pause/play toggle
- 🔵 **Pagination dots** and prev/next buttons
- ♿ **Accessible** — ARIA labels, keyboard focus, reduced-motion support
- 📱 **Fully responsive** — works on all screen sizes

## 🛠️ Run Locally

No build step or package installation required.

**Option 1 — Open directly:**
```bash
open index.html
```

**Option 2 — Local server:**
```bash
python -m http.server 8000
```
Then visit: [http://localhost:8000](http://localhost:8000)
